    WHMCS third-party visibility: inbox modal + addon list «Τρίτος»
    
    Two places now surface whether an invoice routes to a third-party beneficiary,
    so the operator sees it on BOTH sides before acting:
    
    ekdosi inbox «Δημιουργία Παραστατικού» modal:
    - New «Δρομολόγηση σε τρίτους» placeholder (shown only when routing exists)
      lists EVERY routed beneficiary from third_party_resolution — contact name +
      ΑΦΜ + line count + receipt flag — above the recipient selector, so the
      operator sees who the customer chose and can spot a mis-routing before
      picking the recipient. routedBeneficiaries() collapses the resolution lines
      per contact (HTML-entity-decoded names, digit-normalised ΑΦΜ).
    
    WHMCS addon consolidated list:
    - invoice-states endpoint now also returns third_party_state per id.
    - New «Τρίτος» column: Τρίτος (single) / Πολλοί (multi) / — (none) / ·
      (not evaluated), so the third-party picture shows in the WHMCS admin list
      too, not just per-invoice. Plugin → v0.8.0.
    
    States-endpoint test asserts the new third_party_state field. 502 green.
