# Rename.me — υποψήφια ονόματα για το προϊόν

> Καθαρά brainstorming. Ξεκινήσαμε ως **«Έκδοση / ekdosi»** (όπως λεγόταν και η
> παλιά C++ εφαρμογή). Το «έκδοση» έχει ωραίο διπλό νόημα — *έκδοση
> παραστατικού* **και** *software release* — αλλά το νέο προϊόν έχει ξεφύγει
> πολύ από το παλιό (multi-tenant, multi-country, myDATA + WHMCS bridge +
> PEPPOL-ready). Εδώ μαζεύουμε υποψήφια ονόματα για να αποφασίσουμε αργότερα.
> **Καμία απόφαση δεν έχει ληφθεί.**

## Τι κάνει το προϊόν (για να ταιριάξει το όνομα)
Greek-first τιμολογιέρα → πλέον πλατφόρμα έκδοσης & συμμόρφωσης παραστατικών:
εκδίδει νόμιμα παραστατικά, τα υποβάλλει στο **myDATA** (QR/ΜΑΡΚ), γεφυρώνει
**WHMCS** και άλλες πηγές, και ετοιμάζεται για **PEPPOL** (πολυεθνικό:
GR + EE σήμερα). Operators-only, internal.

## Κριτήρια αξιολόγησης
- Σύντομο, εύκολο να προφερθεί GR **και** διεθνώς (έχουμε EE tenant ήδη).
- Ελεύθερο **domain** (.gr / .io / .com) + καθαρό σε **EUIPO / ΓΕΜΗ**.
- Δεν συγκρούεται με γνωστό λογισμικό.
- Να «μυρίζει» ένα από: *έκδοση/εκπομπή*, *ροή/αποστολή*, *εγκυρότητα/σφραγίδα*,
  *λογιστική θαλπωρή*.

|---|---|---|
| **Ekdosis / Έκδοση** | Διπλό νόημα (issue + release)· υπάρχουσα ταυτότητα/ιστορία | αν υπάρχει συναισθηματικός δεσμός, μην το πετάξεις βιαστικά |
| **Emit** | «εκδίδω/εκπέμπω παραστατικό» — το πιο κοντινό μη-ελληνικό | κοντό, app-y, εύκολο domain |
| **Edó / Ekδo** | συντομευμένο, brandable | χάνει το νόημα |

## Δ. Modern / abstract SaaS (Stripe/Linear λογική — μη ελληνικά)
**Ροή / αποστολή** (ταιριάζει στο pipeline WHMCS → ekdosi → ΑΑΔΕ/PEPPOL)
- **Relay** — γεφυρώνει εκδότη ↔ ΑΑΔΕ ↔ PEPPOL· κορυφαίο εννοιολογικά, multi-country friendly.
- **Conduit** — ο αγωγός προς τις αρχές· λίγο πιο μακρύ.
- **Flux** — ροή εγγράφων· κάπως κορεσμένο.

**Λογιστική θαλπωρή**
- **Tally** — «αθροίζω/συμφωνώ»· ζεστό. ⚠ tally.so, Tally ERP.
- **Reckon** — «λογαριάζω»· λίγο enterprise.
- **Abacus** — άβακας· αναγνωρίσιμο, ίσως πιασμένο.

**Εγκυρότητα / συμμόρφωση**
- **Attest** — επίσημη βεβαίωση· ιδανικό για myDATA/PEPPOL.
- **Vouch** — «εγγυώμαι»· κοντό, φιλικό.
- **Verity** — αλήθεια/εγκυρότητα (veritas)· κομψό.
- **Norma** — norm/συμμόρφωση.

**Έκδοση / «κόβω» παραστατικό**
- **Mint** — «κόβω» (νόμισμα/παραστατικό)· καθαρό, μοντέρνο. ⚠ Intuit Mint (έκλεισε).
- **Filer / Filed** — «καταθέτω» στο ΑΑΔΕ.
- **Stamp / Stampa** — σφράγισμα.

**Καθαρό brand (χωρίς νόημα-βάρος)**
- **Crest** — κύρος, καθαρό, εύκολο domain.
- **Lumen / Lume** — διαύγεια/φως.
- **Prism** — ανάλυση/καθαρότητα. ⚠ κάπως πιασμένο.
- **Statera** — Λατινικά «ζυγαριά» (μέτρο/δικαιοσύνη)· κομψό, σπάνιο.

## Συντομευμένη shortlist (η γνώμη μου)
1. **Relay** — καλύτερη περιγραφή του «γεφυρώνω εκδότη ↔ ΑΑΔΕ ↔ PEPPOL»· πιο SaaS, multi-country.
2. **Kýros** — καλύτερο εννοιολογικό ταίριασμα (εγκυρότητα παραστατικών)· κοντό, brandable.
3. **Stoá** — καλύτερο εμπορικό/διεθνές brand που μένει ελληνικό· ουδέτερο για πολλές χώρες.
4. **Emit** — αν θες να κρατήσεις την ψυχή του «έκδοση» σε διεθνές, σύντομο όνομα.
5. **Attest** — αν το μήνυμα είναι «νομική εγκυρότητα/συμμόρφωση».

## Πριν κλειδώσουμε (checklist)
- [ ] Domain: `.gr` **και** `.io`/`.com` ελεύθερα;
- [ ] EUIPO / ΓΕΜΗ / Google: σύγκρουση με λογισμικό ή σήμα;
- [ ] Προφέρεται εύκολα από Έλληνα operator **και** ξένο tenant;
- [ ] Δεν μπερδεύεται με «έκδοση = software version» σε τεχνικά κείμενα;
- [ ] Ταιριάζει σε λογότυπο/εικονίδιο (π.χ. QR/σφραγίδα motif);
